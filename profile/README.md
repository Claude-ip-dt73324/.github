<p>供应商报价单上的计量单位通常有两种：按账号、按设备。两种写法看着只差一个词，实际账单能差出一大截。原因在于账号和设备不是一一对应的：一个人可能在两台机器上登同一个号，一台机器也可能开五个号。按哪个单位收费，决定了你是为「实际使用的对象」付费，还是为「承载它的容器」付费。这篇把两种口径的参数逐项列清楚，给出换算公式，再说明什么规模下按账号开通更省。</p>

<h2>一、两种口径的定义与差异</h2>
<p>按账号计费，指的是每开通一个账号的独立环境收一份费用，不管这个账号在几台设备上登录。按设备计费，指的是每个授权设备收一份费用，设备上开多少账号不影响单价。两种口径各有适用场景，错配就会多付。</p>

<h2>二、按账号开通要问清的六项参数</h2>
<p>决定按账号计费之后，还有六项参数会影响实际支出和使用体验，报价单上不一定写，需要逐项确认。</p>
<h3>参数一：账号绑定是否独占地址</h3>
<p>同样按账号收费，有的产品是每个账号绑定一条独占地址，有的是多个账号共享地址池。前者贵但隔离清楚，后者便宜但地址会轮换。问清楚这一点，比问单价重要。判断方法看合同里有没有写「固定绑定」四个字。</p>
<h3>参数二：换绑次数与冷却期</h3>
<p>账号换地址要不要额外付费、间隔限制是多少。合理的产品会允许每月若干次免费换绑，超出部分按次计费。如果写着「随时换、不限次」，通常意味着背后是共享池在轮转，地址质量难以保证。</p>
<h3>参数三：并发与会话上限</h3>
<p>单个账号允许几个并发连接、会话保持多久。标注 50 并发不代表 50 并发时体验不变，建议按实测拐点的三分之二使用。会话保持时长直接影响长期挂着能不能稳，至少要能撑过一次完整的业务周期。</p>
<h3>参数四：地区粒度</h3>
<p>按账号计费时，地区往往单独定价。同一个账号，指定城市比只指定国家贵三成到一倍。要评估业务是否真的需要城市级，只做对话类业务，州省级通常已够。</p>
<h3>参数五：授权方式与设备限制</h3>
<p>按账号计费的产品有时会附带设备数限制，比如「单账号最多三台设备」。这条限制容易被忽略，等到团队扩设备时才发现要加钱。签约前把这一条单独问清。</p>
<h3>参数六：停用与结转规则</h3>
<p>账号停用后是否立即停止计费、未用完的时长能否结转、淡季能否降档。这三条对季节性业务影响很大，写在合同里比口头承诺可靠。</p>

<h2>三、按设备计费在什么情况下反而更贵</h2>
<p>按设备计费并不是一定更贵，但有两种常见情形会让它变成负担。</p>
<h3>情形一：一人一台机器，但机器上开多个号</h3>
<p>一台机器开五个号，按设备只算一份，看起来省。但如果这五个号需要独立的环境隔离，实际要跑五个虚拟机或五套配置，机器的资源压力会迅速上升，最后不得不加机器。加机器之后，设备数上去了，费用也跟着上去，省下的部分被吃掉。</p>
<h3>情形二：备用设备与临时扩容</h3>
<p>按设备计费通常按授权台数算，备用机、临时扩容的机器都要授权。这类授权在闲置期间仍在计费，而账号计费的模式下，闲置账号可以随时停掉。对于波动大的业务，按账号的弹性更好。</p>

<h2>四、换算公式与场景示例</h2>
<p>两种口径不能直接比单价，要换算到同一个使用形态下再比。公式很简单：把一个月内所有会同时存在的计费单位数出来，乘单价，得到总支出。</p>
<h3>换算的基本公式</h3>
<p>按账号计费时，计费单位数是「在用账号数」；按设备计费时，是「授权设备数」。用两个数字分别乘以各自的单价，比较结果。关键是要用峰值还是均值——建议用均值算常规成本，再用峰值算最坏情况，两个都看。</p>
<h3>三个典型形态的算例</h3>
<p>形态一：一个人管五个号、一台机器。按账号算五份，按设备算一份。若单价接近，按设备便宜。形态二：五个人共管五个号、每人一台机器。按账号算五份，按设备算五份，基本持平，这时候要看哪种的隔离做得更好。形态三：二十个号分布在四台机器、由三人轮班操作。按账号算二十份，按设备算四份，按设备单价若超过账号单价的五倍，按账号就更省。</p>

<h2>五、常见问答</h2>
<h3>一号一环境到底按什么单位算？</h3>
<p>答：按账号算。一号一环境的本质是「一个账号对应一套独立环境」，计费单位自然是账号。按设备算的话，一台机器上跑十个环境却只收一份，供应商通常不会这么定价。</p>
<h3>同一个号在两台设备登录，要付两份吗？</h3>
<p>答：按账号计费只付一份，按设备计费付两份。这也是判断口径的一个方法：看账单上同一个号出现几次。出现两次说明是按设备算的。</p>
<h3>按账号计费能省多少？</h3>
<p>答：取决于账号与设备的比例。账号数是设备数的三倍以上时，按账号通常更省；两者接近时差距不大，这时应该比较隔离能力和运维成本，而不是只看价格。</p>
<h3>淡季能停掉一部分账号吗？</h3>
<p>答：多数按账号计费的产品支持停用即停计费，这是它相对按设备计费的优势。签约前确认停用后是否立即生效、有无最短使用期，这两条决定了弹性是否真实可用。</p>
